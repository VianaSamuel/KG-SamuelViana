# KG-SamuelViana

iOS application built with Swift (UIKit) showcasing a list of upcoming sports events.

## Demo
![Demo](KG.gif)

## Features

- Sports events grouped by category
- Expand/collapse sections
- Real-time countdown timers
- Favorite events with session persistence
- Error handling with retry

## Architecture

MVVM with UIKit, designed for testability and clean separation of concerns.

## Requirements

- iOS 15+
- Xcode 15+
- No third-party dependencies
